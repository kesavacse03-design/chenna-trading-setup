Loading local image into kind or minikube

kind
----
# Build the image locally
npm run docker:build-runworker
# Load image into kind cluster
kind load docker-image cts-run-worker:latest --name your-kind-cluster

minikube
-------
# Build using minikube's docker daemon or load
# Option A: use minikube's docker daemon
minikube -p minikube docker-env | Invoke-Expression
npm run docker:build-runworker
# Option B: build then load
docker save cts-run-worker:latest | (minikube image load -)

Notes
- If using a registry, push with `scripts/push-image.ps1` and update k8s manifests to point to the registry image.
- For kind, ensure the cluster name is correct when using `kind load`.
